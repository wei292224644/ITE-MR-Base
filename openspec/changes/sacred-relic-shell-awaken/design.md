## Context

项目为 Unity MR（XR Hands + XRI），已导入 Dissolve-FX-MasterKit。体验定调：

> **一面年久失修的刻字石板 → 一触引圣光 → 封存朽壳自内渗金溃散（大块→细灰）→ 铭文焕发当年色彩 → 安静收束。**

气质为「圣物苏醒 / 复色」，非阳光灼朽、非手绘擦锈、非碎石爆炸。终点不是「洗白的石头」，而是「字又有了当年的颜色」。

## Goals / Non-Goals

**Goals:**

- 平面刻字石板 Prefab：封存壳 + 本尊石板
- 一触完成：圣金渗出 → 壳溃散（块→灰）→ 铭文朱红复色
- 褪色失修态与朱砂朱红对比清晰可读；金只在溶解边
- 复色后安静收束；Editor 空格/点击可验收（无音效、无浮雕）

**Non-Goals:**

- 手指局部擦拭 Mask
- 预碎刚体
- 真实光照检测触发（首版）
- 逐字书写/打字机动画（首版）
- 匣式开盖圣物
- 本 Demo 音效
- 浅浮雕铭文 mesh（后置）
- 描金作为复色主色

## Decisions

### 1. 形态：平面刻字石板

- **选择**：单面（或为主面）刻字的平面石板，可立可卧放置
- **理由**：用户确认「一面石板，上面刻着字」；双层壳/核与铭文复色都最好落在平面上

### 2. 双层：朽壳溃散 + 本尊复色

- **选择**：
  - **壳**：尘垢/锈败封存层，Burn Dissolve + 块→灰 VFX（见光即溃）
  - **本尊**：同一块石板始终在；铭文从**褪色失修** lerp/reveal 到**当年色彩**
- **理由**：壳负责「千年未见光的封存消散」；复色负责「焕发当年」——两者叠才是完整叙事
- **备选**：仅提亮对比度 — 不够「色彩」；仅 dirty→clean 灰石 — 缺少彩绘/填色归来感

### 3. 铭文复色实现（首版）

- **选择**：Demo 用平面 TMP，颜色从褪色灰 → **朱砂朱红** lerp；金不作为复色主色
- **理由**：probe 确认朱红与圣金溶解边分工；平面字够验证叙事
- **备选**：材质 `_RestoreAmount` 双贴图；浮雕 mesh（后置）

### 4. 触发 = 仪式引光（触碰）

- Editor：空格/点击；可选 XR Poke；字面场景光检测不做
- 验收不要求真手 Poke

### 5. 视觉栈

- 壳：Burn/Custom Dissolve 或轻量 dissolve 回退，暖金/蜂蜜金边
- 大块粒子 → 细灰；无音效
- 本尊：TMP 朱红复色偏中后段；余晖收尽

### 6. 节拍（默认可调 ~2–2.5s）

```
0.0s      触碰锁定
0.0–0.3   触点暖金渗出
0.2–1.5   壳 dissolve + 大块剥落
0.6–2.0   细灰；铭文开始复色（褪色→朱红）
1.2–2.2   朱红接近满；金光余晖
~2.2+     壳隐藏；安静，朱红铭文静置
```

### 7. 代码

- `SacredRelicAwaken`：Sealed → Awakening → Awakened；编排 dissolve、VFX、`_RestoreAmount`；debug reset

## Risks / Trade-offs

- [复色不够「彩」只像变亮] → 褪色态故意去饱和/发灰，彩色态明确色相（朱红/石青等）拉开对比
- [壳溃与复色抢戏] → 复色偏中后段，先让观众看壳散，再看字醒
- [Burn 像烧熔] → 暖金、降边强度；灰用冷色
- [粒子无大块感] → 首段加大片，次段化灰
- [误触重复] → 一次性状态机 + debug reset
